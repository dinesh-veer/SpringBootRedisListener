Redis Configuration

Redis runs on the default Redis port. 


localhost:6379

Spring Boot Configuration

Redis connection properties can be configured in application.properties or application.yml. 


spring.data.redis.host=localhost
spring.data.redis.port=6379

Adjust the values when Redis is running on another host or port.
