Contributing

Welcome

Contributions to SpringBootRedisListener are welcome. If you find a bug, have an improvement, or want to add another Redis example, feel free to contribute.

1. Fork the Repository

Fork the repository on GitHub and clone your fork locally. 

git clone https://github.com/dinesh-veer/SpringBootRedisListener.git

cd SpringBootRedisListener

2. Create a Branch

Create a dedicated branch for your changes. 

git checkout -b feature/my-improvement

3. Make Your Changes

Make your changes while keeping the existing project structure and coding style consistent.

Before submitting your changes, verify that the project builds successfully. 

./mvnw clean test

4. Create a Pull Request

Commit your changes and push your branch. 

git add .

git commit -m "Add Redis listener improvement"

git push origin feature/my-improvement

Then open a Pull Request on GitHub describing your changes.

Open Pull Requests

Contribution Guidelines

  • Keep changes focused and easy to review.
  • Follow the existing Java coding style.
  • Add or update tests when appropriate.
  • Update documentation for new features.
  • Do not commit secrets or credentials.
  • Use meaningful commit messages.
