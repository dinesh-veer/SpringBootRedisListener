Getting Started

Follow these steps to run the Spring Boot Redis Listener application locally.

Requirements

  • Java 21
  • Maven
  • Docker
  • Docker Compose
  • Git

Clone Repository

git clone https://github.com/dinesh-veer/SpringBootRedisListener.git

cd SpringBootRedisListener

Start Redis

Redis can be started using Docker Compose. 

docker compose up -d

Verify that Redis is running: 

docker ps

Redis is exposed on port: 

6379

Run the Application

Build the application using Maven: 

./mvnw clean package

Start the application: 

./mvnw spring-boot:run

Test the Application

Once the application is running, publish a message using the application's publisher mechanism.

The Redis listener subscribes to the configured channel and receives the message asynchronously.
