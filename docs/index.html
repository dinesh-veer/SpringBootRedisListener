Spring Boot Redis Listener

A practical Spring Boot application demonstrating how to publish and listen for messages using Redis Pub/Sub.

Get Started GitHub Repository

Overview

SpringBootRedisListener is a Spring Boot example project that demonstrates Redis message publishing and asynchronous message listening.

Redis Pub/Sub allows one component to publish a message to a Redis channel while one or more subscribers listen to that channel.

Features

Redis Pub/Sub

Publish messages to Redis channels and consume messages asynchronously.

Spring Boot

Uses Spring Boot to configure the application and Redis integration.

Redis Listener

Demonstrates Redis message listener configuration using Spring Data Redis.

Docker Compose

Redis can be started easily using Docker Compose.
